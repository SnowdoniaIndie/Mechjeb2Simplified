# MechJeb2 Simplified

**Version 0.0.1**

MechJeb2 Simplified is a personal fork of MechJeb2 for the Jade modpack. It keeps MechJeb's
autopilot engine but replaces its menus with SimpleAutopilot: one toolbar button per autopilot
that holds whatever the craft is doing when you engage it. The autopilots live on specific parts
rather than every command pod. It's based on MechJeb2 by MuMech (GPLv3) and is for personal use
only.

## What it adds

- Flight Autopilot on the MK2 Drone Core: holds altitude, heading and speed
- Rover Autopilot on the RoveMate: holds heading and speed
- Toolbar buttons that show only when the active vessel carries the right part, with a HUD of the
  held targets above the navball
- A Difficulty Settings toggle to hide MechJeb's own menus (hidden by default)
- MechJeb's aircraft autopilot restored onto the current dev branch
- The magenta map landing prediction turned off by default
